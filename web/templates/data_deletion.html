ACP Data Deletion

You may request deletion of data associated with a Threads account connected to ACP.

How to request deletion

{% if support_email %}
  1. Email {{ support_email }} from an address you can access.
  2. Use the subject ACP Data Deletion Request.
  3. Include the Threads username whose ACP connection should be removed. Do not send your password or access token.
{% else %}

Support contact is not configured yet. The ACP operator must set ACP_SUPPORT_EMAIL before this deployment is submitted for external review.

{% endif %}

What will be deleted

After the request is verified, ACP will remove the stored Threads connection data associated with the requested account, including the stored access token and account-connection identifiers that are no longer required.

What not to send

Never include an Instagram or Threads password, one-time verification code, recovery code, or access token in a deletion request.

Completion

The ACP operator will confirm when the deletion request has been completed. Information that must be retained for security, fraud-prevention, legal, or audit obligations may be retained only for the period required for those purposes.
